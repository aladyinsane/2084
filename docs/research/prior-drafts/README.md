# Prior drafts

Design material written **before** this repo adopted the research → principles → ADR
workflow. Kept as research inputs, not as canon.

| Doc | What it is | Status |
|---|---|---|
| [copilot-brainstorm.md](copilot-brainstorm.md) | Free-form feature brainstorm ("the world is the antagonist", surveillance progression, memory integrity, cells, bureaucracy-as-gameplay) | Mined. Its best ideas survive as principles and ADRs; the rest sits in the [parking lot](../../product/future-features.md) |
| [2084-codex.md](2084-codex.md) | Early world codex: the Grid, ministries, factions, districts, NPC archetypes | Partially superseded. Lore/naming largely stands; its "player roles" section conflicts with [ADR 0002](../../decisions/0002-no-race-no-class.md) and is superseded by it |
| [2084-mechanics-design.md](2084-mechanics-design.md) | Early mechanics draft: Exposure, Influence, memory objects, watch checks, with Evennia pseudo-code | Partially superseded. Core ideas ratified (with changes) by ADRs 0003–0006; numbers and code snippets are illustrative, not binding |

Rule of precedence: **an ADR beats anything in this folder.** Where a prior draft says
one thing and an ADR says another, the ADR wins and the draft is not edited to match —
these files are frozen as historical record, same reasoning as ADR immutability.
